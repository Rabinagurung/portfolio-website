# Personal Portfolio Website

This is my personal portfolio website, built to showcase my work, experience, technical skills, and projects in a clean interactive format.

The site is built with React, Vite, Tailwind CSS, Framer Motion, and Three.js. It includes sections for my introduction, work experience, technology stack, projects, and contact information.

## Running Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser to view the site.
